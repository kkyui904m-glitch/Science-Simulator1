🔬 [실험 5] 미세유체 세포 압축 칩(Microfluidic Cell Squeezing) 변인 조작

보고서 본문 사례 ③의 "세포막을 일시적으로 여는 미세유체 칩(Cell Squeezing) 기계 기술" 실험입니다. 면역 T세포/조혈모세포(지름 12μm)를 좁은 미세 채널로 통과시킬 때 채널 폭과 유속을 조작하여 세포를 죽이지 않으면서 유전자가위 전달 수율(Yield)을 극대화하는 최적 조건을 찾아보세요!

생명과학 × 기계공학(미세유체역학) 핵심 트레이드오프(Trade-off) 원리:
• 채널이 너무 넓으면(>8μm): 세포 생존율은 97% 이상이지만 세포막에 기공이 안 열려 유전자가위가 못 들어갑니다.
• 채널이 너무 좁거나 유속이 너무 빠르면(<4.5μm, >300mm/s): 과도한 전단 응력(Shear stress)으로 세포막이 영구 파열(Lysis)되어 세포가 죽습니다.
• 최적점: 세포 지름(12μm)의 50%인 6.0μm 채널 + 200mm/s 유속에서 최종 수율(70.9%)이 극대화됩니다!

🧭 [실험 6] 2D Y자 혈관 분기점 마이크로 로봇 PID 자동 조향 제어 실험

실제 혈관은 Y자로 갈라지며 심장 박동에 의한 맥동 혈류 교란(Pulsatile disturbance)이 로봇을 위쪽(정상 장기 혈관)으로 밀어냅니다. 컴퓨터·기계제어공학의 PID 피드백 제어 게인(Kp, Kd)을 조작하여 로봇을 아래쪽 🎯 표적 종양 혈관으로 정확히 조향해 보세요!

기계·로봇제어공학 PID 피드백 조향 방정식:
• 오차 e(t) = y_target(t) - y_robot(t)
• 자기장 조향 제어 입력 u(t) = Kp · e(t) + Kd · (de(t)/dt)
• Kp = 0(무제어)이면 맥동류 편향에 밀려 위쪽 정상 장기 혈관으로 잘못 들어가며, Kp = 2.5, Kd = 0.8일 때 오차(RMSE)가 5.5μm로 최소화되어 아래쪽 종양 혈관으로 완벽히 진입합니다!
